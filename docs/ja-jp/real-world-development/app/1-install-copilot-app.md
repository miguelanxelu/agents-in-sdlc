**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使うデスクトップアプリケーションです。GitHub Copilot CLI を基盤として GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。すべての作業を自分で行うのではなく、それぞれ独立したワークスペースで複数のエージェントを並列に動かして指示し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトのコピーが完了したので、アプリをインストールしてリポジトリに接続します。

このレッスンでは、次の作業を行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートによって用意されたバックログを含め、ワークスペースを確認します。
- クイックチャットを試して、アプリ自体について質問します。

## シナリオ

チームは、増え続けるバックログに対応するために AI エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise の場合、管理者が **GitHub Copilot app** ポリシーを有効にしている必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加します。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストールが完了したら、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地機能を使う GitHub Enterprise Cloud の場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server には対応していません。
5. オンボーディングでリポジトリを選択する画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリの選択をスキップし、オンボーディング後に追加することもできます。
6. テーマを選ぶよう求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** の下にリポジトリが表示されているか確認します。すでに表示されている場合は、もう一度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで控えた所有者名とリポジトリ名を使います。
9. リポジトリがサイドバーに表示されることを確認します。このレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にまとめられ、それぞれのリポジトリの下に個別のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認します。サイドバーには次の領域があります。

- **New** - Copilot との新しいチャットセッションを開始します。
- **Pull requests** - アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに参照、絞り込み、継続的インテグレーション (CI) の状態確認、レビューができます。
- **Issues** - issue を参照、絞り込み、選択してセッションを開始します。
- **Automations** - スケジュールまたはオンデマンドで実行する、保存済みのエージェントタスクです。To Do リストの管理、定期的なプロジェクト保守、その他の手間のかかる作業に役立ちます。まとめでは次のステップとして紹介しますが、ワークショップ内の演習ではありません。
- **Customize** - MCP サーバー、プラグイン、スキルなどを追加して Copilot app の機能を拡張します。Playwright MCP の設定で使用します。
- **Chats** - 独自のブランチやワークスペースが必要ない、質問やブレインストーミング向けの簡易的な会話です。最初のチャットを開始すると表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択してチャットを始めます。
- **Sessions** - リポジトリフォルダーと、そのエージェントセッションをまとめます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリビューが開き、その下のセッションを選択すると会話に戻ります。セッションごとに独立したワークスペースで動くため、変更を競合させずに複数のセッションを実行できます。星評価を追加するレッスンで、最初のセッションを開始します。

ワークショップを進めながら、ワークスペースの各機能を確認します。

> [!TIP]
> 操作方法がわからない場合や、何かが可能か知りたい場合は、Copilot に質問してください。手順を案内してくれます。

### 用意されたバックログを確認する

ほとんどのプロジェクトにバックログがあり、Tailspin Toys も例外ではありません。テンプレートからリポジトリを作成したときに用意されたバックログを確認します。

1. サイドバーの **Sessions** の下にある Tailspin Toys のリポジトリフォルダーを選択します。フォルダーの下にある個別のセッションではありません。次に、リポジトリの上部ナビゲーションで **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルを探します。
   - Allow users to filter games by category and publisher
   - Update our repository coding standards
3. issue を選択して詳細を読みます。各 issue からエージェントセッションを開始できます。最初の小さな変更を完了した後、フィルター機能の issue から作業を開始します。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。他のリポジトリの作業項目を表示するには、そのリポジトリをアプリに追加します。

## クイックチャットを試す

アプリ自体について質問すると、アプリに慣れることができます。**クイックチャット**ではブランチや worktree を作成せずに質問やブレインストーミングができるため、セッションを必要としない、その場限りの質問に適しています。

1. サイドバーの **Chats** の横にある **+** を選択して、新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。その後 **Chats** が表示されます。
2. アプリのセッションの仕組みについて、次の質問を送ります。

   ```plaintext
   GitHub Copilot app では worktree をどのように使いますか。
   ```

3. 会話ビューで回答を読みます。各セッションが独立した Git worktree で実行されるため、変更を競合させずに複数のエージェントを並列で動かせることがわかります。会話は続けることも、新しいチャットを始めることもできます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースを確認しました。次の作業を行いました。

- アプリをインストールして GitHub にサインインしました。
- GitHub リポジトリからプロジェクトを追加しました。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つけました。
- クイックチャットで、その場限りの質問をしました。

次は、[最初のエージェントセッションを開始し][next-lesson]、ゲームカードに星評価を表示します。
